Description: An android RGB background selector.

Use the three sliding bars to adjust the red, green and blue of the background. 
When you've found a selection you like, click the save button. This will reset the screen, but the color can be selected from the list below the save button.
For user convenience, the colors hex code is displayed below the sliders.
Quality of life feature: when the background is bright, the text will turn black. When it is dark, the text will turn white.
